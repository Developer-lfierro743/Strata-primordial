10. WHY MINECRAFT 2 MUST EXIST — THE TECHNICAL CASE
====================================================================
The engine is a 2009 weekend hobby project carrying 17 years of patch debt.

Aging Java codebase & technical debt:
- Minecraft: Java Edition was written by Notch in a weekend as a hobby
  project in 2009. Two decades of updates sit on that foundation.
- Mojang refactors pieces (chunk saving, lighting engine) but the core is
  legacy spaghetti — you cannot fix 2009 architecture decisions with
  patches. Every modern feature is built AROUND bottlenecks, not through
  them.

Performance: single-threaded tick loop:
- Server game logic (player movement, mob AI, redstone, chunk saving,
  block updates) runs mostly on ONE CPU thread at 20 TPS (one tick every
  50ms). Exceed 50ms and the server drops ticks -> global slow-motion lag.
- Server hosts confirm: adding a 16- or 32-core CPU gives ~zero benefit to
  a vanilla server — it is single-thread-performance bound (IPC + clock).
  (Source: Server Heron)
- Java GC stutters: millions of short-lived objects per second (block
  updates, particles) cause garbage-collection pauses -> micro-freezes.

Rendering is a band-aid, not a fix:
- Java Edition used OpenGL for 17 years — an API that never leveraged
  multi-core or modern GPU features.
- CONFIRMED Feb 18, 2026 (minecraft.net, Tom's Hardware, TechSpot, Khronos): Mojang is switching Java Edition from OpenGL to Vulkan. Update Aug 26, 2026: Vulkan is LIVE as experimental toggle in 26.2 snapshots (Video Settings -> Graphics API -> Prefer Vulkan). Requirements: Vulkan 1.2 + dynamic rendering/push descriptors, discrete GPU preferred, MoltenVK translation on macOS, Java 25.
- Early benchmarks (Nemez Apr 10, 2026): NVIDIA RTX 5090 +31% vs OpenGL, but AMD/Intel regressions up to -48% to -58% on Vulkan in 26.2 snapshot — proves Vulkan alone doesn't fix a weak engine. Mojang admits OpenGL mods will need major rewrites, will run Vulkan/OpenGL side-by-side in snapshots through summer 2026 before removing OpenGL.
- CONFIRMED July 16, 2026 (minecraft.net, GamingOnLinux, Beebom): Minecraft Java 26.3 Snapshot 4 ditched GLFW for SDL3 — exact same library Strata uses. GLFW was unmaintained since Feb 2024; SDL3 brings native Wayland (preferred on Linux), borderless fullscreen default, 48-button mouse rebinding, scancode/keycode input separation. LWJGL bindings by GTNH modpack contributor. Validates Strata's SDL3 bet but also means Mojang is modernizing the same layer.
- But patching a 2009 engine to Vulkan/SDL3 is still a retrofit. A native engine
  built for Vulkan/SDL3 from day one is what Strata IS.

The Java/Bedrock split can never be fixed:
- Two versions in two languages (Java vs C++). Parity gaps in redstone
  timing, mob AI, chunk loading are PERMANENT — content parity ~done by
  2026, technical parity never will be.
- A unified native engine (like Strata's KMP/Native core) eliminates the
  split: one codebase, uniform mechanics, cross-play by default.

Modding API is a fragile reverse-engineering racket:
- Java mods (Forge/Fabric) work by reverse-engineering obfuscated code;
  every major update breaks the ecosystem and forces rewrites.
- Bedrock's official Scripting API is locked down vs Java mods.
- A real, official, native modding API (Strata's planned .kts/plugin API)
  is a documented gap.

What a modern engine fixes (Strata checklist):
1. True multithreading: worldgen, meshing, lighting, physics, pathfinding
   across all cores — Strata already pipelines worldgen + meshing on
   worker coroutines.
2. Native memory management: no JVM GC spikes, far lower RAM.
3. Modern GPU pipeline natively: ray tracing, mesh shaders, compute —
   not via third-party shader packs (Iris/OptiFine) bolted onto OpenGL.
4. Huge render distances without destroying frame rates.

Sources: Tom's Hardware (Vulkan renderer), Server Heron (single-thread
lag), Minecraft Feedback (Bedrock API limits), LTT Forums (multi-threading).

12. NOTCH'S ORIGINAL IDEAS THAT WERE SCRAPPED / NEVER SHIPPED
====================================================================
The pattern: Notch's grand vision kept getting cut for scope, time,
performance, or because he left. This is the blueprint of "ideas Mojang
abandoned" — exactly the vacuum Strata's Formula docs fill.

1. Sky Dimension -> became The End (2011-2012):
   - Teased May 19, 2011: a light/heavenly counterpart to the Nether, with
     floating islands and peaceful Overworld-like generation.
   - Killed by performance: top-down lighting created heavy shadows + lag
     across vast open heights.
   - Oct 12, 2011: rebranded/reworked into The End — a dark void with the
     Ender Dragon boss. Floating-island heaven never shipped.

2. Red Dragon -> Ender Dragon (2010-2011):
   - Notch mentioned dragons during the Secret Friday Updates (late
     2010/early 2011); planned multiple dragon types.
   - When 1.0 needed a final boss, the Ender Dragon was built for The End.
   - Notch kept musing about a tameable/breedable Overworld Red Dragon
     (hatching from dungeon eggs) — never implemented; shelved after he
     left in 2014.

3. The 2009 "Planned Features" list (minecraft.net):
   - Listed: copper, tin, silver, amethyst ores; expanded tool tiers;
     furniture; traps.
   - Dropped or back-burnered for over a decade. Copper only arrived in
     1.17 Caves & Cliffs (2021); tin/silver never; amethyst arrived 1.17
     as a completely different crystal.
   - Lesson: Notch-era feature lists were promises, not product.

4. Minecraft 2.0 April Fools (Apr 1, 2013):
   - Fake "Minecraft 2.0" changelog + builds forked from 1.5.1. Joke
     features: Etho Slab (TNT slab), burnt-out torches, block of coal,
     tinted glass, pink Withers, diamond chickens, redstone bugs, Super
     Hostile Mode.
   - Fan favorites were later folded in for real (block of coal, stained
     glass in 1.6/1.7). Even the joke had more feature velocity than the
     live game.

5. "Greenstone" ore:
   - FACT CHECK: Notch never officially planned greenstone. It's a
     long-running community myth/conflation with redstone. Strata's
     Greenstone is an ORIGINAL concept — do not frame it as "Notch's idea."

6. Villagers vs human NPCs:
   - Early plans imagined human-ish NPCs; what shipped were the
     "Testificates" (villagers) in 1.0. The rich NPC/village simulation
     Notch described was never fully realized.

Implication for Strata:
- Mojang's history = cut ideas, broken promises, and a corporate hand
  that abandons vision for MAU. Strata's Formula docs (Sky dimension,
  furniture, vertical slabs, Greenstone, Infernite, double hearts, The
  Purge) are precisely the "Notch-era dreams" the incumbent abandoned —
  claim that heritage openly.
